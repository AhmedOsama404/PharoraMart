# I18nService

- File: `src/app/core/services/i18n.service.ts`. Spec: `i18n.service.spec.ts`.
- Root singleton; runtime language engine (custom, signal-based — no external
  i18n library, which keeps RTL/bundle behavior fully controlled).

## Responsibility

Active language, direction, translation lookup with `{param}` filling,
persistence, and `<html lang dir>` management.

## Public API

- `currentLang: Signal<SupportedLang>` (8 languages), `dir` (`rtl` only for
  `ar`), `version` (bump signal so template calls re-evaluate).
- `t(key, params?)` — nested lookup; missing keys return the key itself
  (loud, greppable); reads signals so templates update without reload.
- `setLang(lang)` — validates, persists (`novamart.lang`), applies DOM attrs.
- `isRtl()`.

## Dependencies

`i18n.config.ts` (`SUPPORTED_LANGS`, `LANG_LOCALES`, `LANG_DIRS`, dicts).

## Consumers

Every template (`i18n.t`), `CurrencyService`, `LocalizedTitleStrategy`,
`categoryName()`, contact messages, validation/toast keys.

## Tests

Eight-language support, default EN, instant switch + persistence + DOM attrs,
RTL-only-Arabic across all languages, refresh restore, interpolation,
placeholder parity, key consistency (200+ keys), no empty values.

## Safe extension

New language: dictionary + `i18n.config.ts` (see LOCALIZATION.md). Never
hardcode strings in components.
